# 在庫ノート — 個人用在庫管理 PWA

仕事の消耗品・厨房用品・備品・工具・事務用品・家庭用品を、**何が・どこに・いくつ・いくらで**あるか一目で分かるように管理する、iPhone 向けの Web アプリ（PWA）です。

- ログイン・サーバー・広告・解析なし。データはすべて端末内（IndexedDB）に保存
- オフラインで全機能が動作（ホーム画面に追加して使用）
- 依存ライブラリ・ビルド工程なし（素の JavaScript）。10年後も同じファイルで動きます

## 主な機能

| 区分 | 内容 |
|---|---|
| 在庫一覧 | リスト／カード切替（記憶）、キーワード検索（全角半角・カナの揺れ吸収）、カテゴリ・保管場所・管理区分・在庫状態・アーカイブで絞り込み、商品名・在庫数・単価・購入日・登録日・最近の操作で並び替え、数量タップでクイック操作 |
| 商品 | 必須は商品名と単位のみ・在庫0で登録可、詳細項目は折りたたみ、写真（撮影／ライブラリ・複数・並び替え・メイン指定）、JAN・商品名による重複チェック（「既存に入庫」／「別商品として登録」） |
| 在庫操作 | 入庫（箱×入数＋バラ・購入総額・税込/税抜・購入日/入庫日/保管日・購入店・URL）、使用、保管場所間の移動、棚卸し。FIFO＋手動ロット指定。操作直後の取り消し、履歴からの訂正・取り消し（元履歴は保持）、過去日付の操作と自動再計算 |
| 単価の表示 | 一覧・詳細に最新の購入単価を「1ロール 約¥67」の形で表示。入庫時は購入総額から1個あたり・1袋あたりの単価を自動計算 |
| 印刷 | 在庫一覧の「選択」で商品を選び、在庫一覧表（保管場所・数量・箱換算・単価・在庫金額・実数記入欄など）を印刷／PDF保存 |
| 金額 | 購入分ごとの単価、残存在庫金額、加重平均単価。税込・税抜は別集計、価格未設定は0円扱いしない、算出できない場合は「算出不可」 |
| 警告 | 商品ごとの警告ラインで「在庫少」「在庫切れ」、要補充の絞り込み、タブバーのバッジ |
| スキャン | iPhone カメラで JAN（EAN-13/8）を読み取り、登録済みなら商品と操作、未登録なら JAN を引き継いで新規登録。手入力可。未登録の JAN は「ネットで商品名を調べる」で Google 検索を開ける（利用者が押したときだけ） |
| 保管場所 | 管理区分（仕事用・家庭用など）ごとの場所一覧、場所別の在庫と金額、詳細位置（棚2・上段など） |
| 区分の切り替え | 在庫・保管場所・履歴の上部タブで「すべて／仕事用／家庭用」を切り替え。選んだ区分の保管場所にある在庫だけで数量・要補充を表示（選択は記憶） |
| CSV | 商品一覧・購入履歴・全履歴の出力（UTF-8 BOM）、取り込み（新規・既存更新・入庫・棚卸し、プレビューとエラー行表示、重複確認） |
| バックアップ | 写真を含む全データを ZIP に保存、全件置き換え／重複チェック付き統合で復元、検証・二重取り込み防止、7日ごとのリマインダー（変更時のみ） |
| その他 | ライト／ダーク／OS連動、セーフエリア対応、サンプルデータ（本番と別領域）、整合性チェック |

## 開発・起動

必要なもの：Python 3（macOS に標準搭載）とブラウザ。Node.js や npm は不要です。

```bash
python3 tools/serve.py 8765
```

- アプリ：<http://localhost:8765/>
- 自動テスト：<http://localhost:8765/tests/>（ブラウザで開くと全テストが実行され、合格／不合格が一覧表示されます）

開発中は古いキャッシュで混乱しないよう、localhost では Service Worker を登録しません。オフライン動作を localhost で試す場合は、ブラウザのコンソールで `localStorage.setItem('zaiko.sw','1')` を実行して再読み込みしてください。

ファイルを追加・変更して公開する前に、Service Worker のキャッシュ一覧とバージョンを更新します：

```bash
python3 tools/build_sw.py
```

アイコンを作り直す場合：`python3 tools/make_icons.py`

## iPhone で使う（インストール手順）

iPhone のカメラ・Service Worker（オフライン）・ホーム画面追加には **HTTPS** での配信が必要です。このフォルダをそのまま静的ホスティングに置くだけで動きます（サーバー側の処理は不要）。

1. **公開**（いずれか1つ。どれも無料枠で可）
   - GitHub Pages：リポジトリにこのフォルダの中身を push → Settings → Pages で公開
   - Cloudflare Pages / Netlify：管理画面にフォルダをドラッグ＆ドロップ
   - 公開前に `python3 tools/build_sw.py` を実行しておく
2. iPhone の **Safari** で公開 URL を開く
3. 共有ボタン → **「ホーム画面に追加」** → 追加
4. ホーム画面の「在庫ノート」アイコンから起動（以後オフラインでも使えます）
5. スキャン画面で「カメラを起動」→ カメラの使用を許可

注意：
- データはその URL（オリジン）ごとに、その iPhone の中に保存されます。URL を変えると別のデータになります。
- Safari の「履歴とWebサイトデータを消去」を行うとデータが消えます。**定期的に 設定 → バックアップを作成** で iCloud Drive などに保存してください。
- ホーム画面に追加したアプリと、Safari のタブで開いたページは保存領域が別になる場合があります。普段はホーム画面版を使ってください。
- 公開した URL は他人もアクセスできますが、データは各自の端末内にあり、サーバーには送られません。
