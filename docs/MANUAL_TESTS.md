# 手動テスト手順

自動テストでは確認できない、デザイン・iPhone 実機・カメラ・バーコード・PWA 操作の確認手順です。
**結果欄は、実施していないものはすべて「未実施」です。** 実施したら「合格／不合格」と日付・端末を記入してください。

前提：アプリを HTTPS で公開し（README「iPhoneで使う」参照）、iPhone の Safari で開く。サンプルデータで行う項目は 設定 → 「サンプルデータで試す」。

| # | 区分 | 手順 | 期待結果 | 結果 |
|---|---|---|---|---|
| M1 | PWA | Safari で開き、共有 → 「ホーム画面に追加」→ ホーム画面のアイコンから起動 | アドレスバーなしの全画面で起動。アイコン・名前「在庫ノート」が表示される | 未実施 |
| M2 | PWA | ホーム画面版を一度起動後、機内モードにして再起動。商品登録・入庫・使用・履歴閲覧 | すべて動作し、データが保存される | 未実施 |
| M3 | PWA | 新バージョンを公開（`tools/build_sw.py` 実行後に配置）→ アプリ起動 | 「新しいバージョンがあります」→ 更新でリロード。データは残る | 未実施 |
| M4 | セーフエリア | iPhone（ノッチ／Dynamic Island 機種）で縦向き表示 | 上部の見出し・下部タブバーがステータスバーやホームインジケーターに重ならない | 未実施 |
| M5 | デザイン | 設定 → テーマを 自動／ライト／ダーク に切替。自動時に iOS の外観を切替 | 即座に反映。自動は OS に追従。再起動後も維持 | 未実施 |
| M6 | 片手操作 | 片手（親指）で：一覧 → 数量をタップ → 使用 → 場所ボタン → ＋ → 記録 | 主要ボタンが画面下半分にあり、指が届く。タップ領域が小さすぎない | 未実施 |
| M7 | 入力 | 入力欄をタップ | 画面が勝手に拡大しない（16px 以上）。数量欄は数字キーボード | 未実施 |
| M8 | 写真 | 商品編集 → 「撮影」でカメラ撮影、「ライブラリ」で複数枚選択、並び替え、削除、保存 | 撮影・選択した写真が縮小保存され、先頭がメインとして一覧に表示 | 未実施 |
| M9 | 写真 | HEIC 写真（iPhone 標準形式）をライブラリから追加 | JPEG に変換されて保存・表示される | 未実施 |
| M10 | カメラ | スキャン → カメラを起動 → 初回の許可ダイアログで許可 | 背面カメラの映像が表示される | 未実施 |
| M11 | バーコード | 実物の JAN（13桁）商品を枠内に横向きで写す | 1〜3秒程度で読み取り、登録済みなら商品と操作ボタン、未登録なら「このJANで新規登録」 | 未実施 |
| M12 | バーコード | JAN-8（8桁）の商品、上下逆さまの向き、暗い場所 | 読み取れる（暗所は読めない場合あり → 未検証事項） | 未実施 |
| M13 | バーコード | 商品登録画面の JAN 欄の「スキャン」 | 読み取った値が JAN 欄に入り、重複チェックが行われる | 未実施 |
| M14 | カメラ拒否 | iOS 設定でカメラを拒否してスキャン | 許可方法の案内が表示され、手入力で検索できる | 未実施 |
| M15 | バックアップ | 設定 → バックアップを作成 → 共有シートで「ファイルに保存」 | ファイルアプリに ZIP が保存され、最終バックアップ日時が更新される | 未実施 |
| M16 | バックアップ | 共有シートをキャンセル | 最終バックアップ日時は更新されない | 未実施 |
| M17 | 復元 | M15 の ZIP を 設定 → 復元 → 統合 / 全件置き換え | 件数・競合のプレビュー後に復元。在庫数・写真が元と一致 | 未実施 |
| M18 | 復元 | 別の ZIP や壊れたファイルを選択 | 検証エラーが表示され、データは変わらない | 未実施 |
| M19 | CSV | 商品一覧 CSV を出力し、Numbers と Excel（iPhone/Mac）で開く | 日本語が文字化けせず、列が正しく分かれる | 未実施 |
| M20 | CSV | テンプレートを Numbers で編集して保存（CSV書き出し）→ 取り込み | プレビューでエラー行・重複候補が表示され、確定後に反映 | 未実施 |
| M21 | リマインダー | 本番データで変更後、端末の日付を8日進めて起動 | 「前回のバックアップから8日経過」のバナー。バックアップ後は消える | 未実施 |
| M22 | 容量 | 設定 → 保存容量の表示、「永続化を要求」 | 使用量が表示される。ホーム画面版では永続化が許可されやすい | 未実施 |
| M23 | 複数タブ | Mac の Safari で2タブ開き、一方で入庫 | もう一方にも反映される | 未実施 |
| M24 | サンプル分離 | 本番で1件登録 → サンプルで試す → サンプルをリセット → 終了 | 本番の1件がそのまま残る | 未実施 |
| M25 | 長期利用 | 商品500件・履歴5,000件程度で一覧スクロール・検索 | 実用的な速度で動作する | 未実施 |
