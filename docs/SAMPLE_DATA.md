# サンプルデータの内容と検証観点

サンプルは本番とは別の IndexedDB（`zaiko-sample`）に作成されます。設定 → 「サンプルデータで試す」で切り替え、「サンプルをリセット」で初期化。本番データ（`zaiko-main`）には一切触れません。
日付はすべて「今日から◯日前」の相対日付で作成されます（いつ読み込んでも自然に見えるように）。写真は端末上でキャンバス描画により生成します（外部画像の取得なし）。

管理区分：仕事用（倉庫A・厨房・事務所）／家庭用（自宅パントリー・自宅ガレージ）
カテゴリ：衛生用品・厨房用品・消耗品・事務用品・工具・家庭用品
